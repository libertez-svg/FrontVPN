# FrontVPN

Интерфейс VPN-клиента. Сделан на HTML, CSS и JS без сторонних библиотек и сборщиков.

## Что тут есть

- **Подключение**: кнопка коннекта, таймер, динамическая скорость (вход/исход), статус скрытия IP и плашка текущего сервера.
- **Список серверов**: 20 локаций (Германия, Нидерланды, США и др.), SVG-флаги вместо эмодзи, поиск по городам и странам, фильтры (все, избранные, быстрые, недавние).
- **Статистика**: график суточного расхода трафика, счетчики отданного/принятого объема и времени в сети.
- **Настройки**: протоколы (WireGuard, OpenVPN, IKEv2), тумблеры Kill Switch, автоподключение, раздельное туннелирование, блокировка рекламы.
- **Адаптив**: на десктопе боковое меню, на телефонах переключается в нижний таббар как в мобильном приложении.

## Запуск

Просто открыть `index.html` в браузере.
